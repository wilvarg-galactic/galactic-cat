Galactic CAT

Galactic CAT es una herramienta de traducción asistida (CAT) para localización de videojuegos, basada en OmegaT. Permite trabajar sobre las traducciones de un proyecto y, si el usuario lo autoriza, sincronizarlas con una hoja de cálculo de Google Sheets.

Conexión con Google: la aplicación únicamente accede a las hojas de cálculo de Google que el propio usuario autoriza expresamente, y solo para leer el texto original y escribir las traducciones de ese documento. Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions.
