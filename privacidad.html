Política de privacidad de Galactic CAT

Última actualización: octubre de 2026.

Qué es Galactic CAT

Galactic CAT es una aplicación de escritorio de traducción asistida (CAT) para localización de videojuegos, basada en el programa de código abierto OmegaT. Se ejecuta en el ordenador del usuario y no envía datos a ningún servidor propio: el programa no tiene servidores.

Qué datos de Google se usan

Si el usuario pulsa «Conectar...» y concede el permiso, Galactic CAT accede a las hojas de cálculo de Google mediante la API de Google Sheets, con el permiso https://www.googleapis.com/auth/spreadsheets, y únicamente para:

  • leer el texto original y las traducciones de la hoja que el propio usuario indique;
  • escribir las traducciones en esa misma hoja cuando el usuario lo pida expresamente.

Qué NO se hace con esos datos

  • No se recopilan datos personales.
  • No se envía el contenido de las hojas a terceros.
  • No se usa para publicidad ni se vende.
  • No se accede a ninguna hoja que el usuario no haya autorizado.

Dónde se guarda el permiso

El permiso de Google se guarda solo en el ordenador del usuario, en el fichero de configuración del programa. No se comparte con nadie.

Cómo retirar el permiso

El usuario puede retirar el acceso en cualquier momento desde myaccount.google.com/permissions (selecciona Galactic CAT y pulsa «Quitar acceso»).
